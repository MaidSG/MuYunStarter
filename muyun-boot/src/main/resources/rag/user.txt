4. 微服务架构图描述（文本 + 伪代码）
服务拓扑：
- API Gateway (Kong)
  ↳ 路由至 auth-service / order-service
- auth-service (JWT签发)
  ↳ 依赖 Redis 缓存令牌
- order-service (处理订单)
  ↳ 发送领域事件到 Kafka Topic: order_events
  ↳ 使用Saga模式管理分布式事务

通信协议：
| 服务间调用 | gRPC (Protocol Buffers) |
| 客户端通信 | REST/JSON over HTTPS |
